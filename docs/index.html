Build an Interactive RGB Light Experience

Build a visionOS app with RealityKit that places three glowing red, green, and blue spheres in an immersive space, where you pick them up and move them with your hands. Bring two spheres together and you can pull a new mixed-color sphere, such as yellow, magenta, or cyan, out of the overlap. Finally, rotate your right wrist to adjust the brightness of a selected sphere.

Estimated Time25 minutes
Testing note — You can build the project and inspect the immersive layout in the visionOS Simulator. For the intended direct hand interaction and spatial depth, run the finished experience on Apple Vision Pro.
Section 1 of 6

Create the Immersive Space

Start by creating the immersive space where the RGB spheres will appear. The app starts in a regular SwiftUI window; when the user opens the immersive space, RealityKit creates a separate 3D environment where the RGB spheres will be placed and interacted with.

Step 1

Create the Project

In Xcode, choose File → New → Project…, select the visionOS tab, and choose the App template under Application.

Step 2

Choose the Project Options

Enter a product name, then set Initial Scene to Window, Immersive Space Renderer to RealityKit, and Immersive Space to Full. The app starts in a window and opens a full immersive space.

Step 3

Create the App Model

The AppModel keeps track of the immersive space's current state. immersiveSpaceID identifies the immersive space, while immersiveSpaceState tracks whether the space is closed, in transition, or open.

Step 4

Define the App's Scenes

The App structure defines both the regular window and the immersive space. The WindowGroup displays the initial SwiftUI interface; the ImmersiveSpace scene contains the ImmersiveView. When the space appears the state becomes open, and returns to closed when it disappears.

Step 5

Open and Close the Immersive Space

openImmersiveSpace opens the space by identifier and dismissImmersiveSpace closes it. The inTransition state disables the button while the space is opening or closing.

Step 6

Create the Initial View

The regular window only needs a button to enter the immersive experience. At this point the app can open and close an empty immersive space — the RGB spheres come next.

Create the RGB Spheres

    
Create the visual representation of each RGB light using RealityKit
    entities, materials, and a radiating glow. Each sphere is a
    ModelEntity with a spherical mesh, a colored material, and
    an RGB color value.

  

  






  

    

      
Step 1

      
Store RGB Color

      
＋ New file: SphereComponents.swift

      
The RGBColorComponent stores the RGB color associated
      with a sphere, keeping the color data attached to the entity itself.

      

    

    

      
Step 2

      
Create a Sphere

      
＋ New file: RGBSphere.swift

      
A ModelEntity combines a mesh and materials to create
      a visible object. The makeRGBSphere function creates a
      sphere with a radius of 0.15 meters and stores its color
      using RGBColorComponent.

      

    

    

      
Step 3

      
Create the RGB Colors

      
＋ New file: RGBColor.swift

      
The RGBColor structure stores red, green, and blue
      values separately — Red (1, 0, 0), Green
      (0, 1, 0), Blue (0, 0, 1).
      Keeping RGB values separate from the visual color makes it possible to combine them
      later.

      

    

    

      
Step 4

      
Create the Sphere Material

      
The sphere uses a PhysicallyBasedMaterial that combines
      its base color with transparency and emissive color to create a luminous
      appearance.

      

    

    

      
Step 5

      
Add a Radiating Glow

      
A second visual layer creates the soft glow around each sphere: a radial gradient
      texture applied to a plane, kept facing the viewer by a
      BillboardComponent. The glow is visual only.

      

    

    

      
Step 6

      
Place the RGB Spheres

      
Create the three spheres in ImmersiveView's
      RealityView, position them in front of the user, and add
      them to a head anchor. At this point the spheres are visible in the immersive space,
      but they cannot be manipulated yet.

Section 3 of 6

    
Make the Spheres Interactive

    
Mark the three spheres as fixed originals, then add the components
    and event handling needed to make the spheres selectable and movable in the immersive
    space.

  

  






  

    

      
Step 1

      
Identify Original Spheres

      
The OriginalSphereComponent identifies an original
      sphere and stores its fixed position — so the three original spheres remain in place
      while movable copies are created for interaction.

      

    

    

      
Step 2

      
Prepare a Sphere for Interaction

      
＋ New file: SphereInteraction.swift

      
The configureSphereForInteraction function adds an
      InputTargetComponent so the sphere can receive input, a
      CollisionComponent that defines the collision and
      interaction area, and a ManipulationComponent that lets
      the user move the sphere directly.

      

    

    

      
Step 3

      
Handle Manipulation Events

      
＋ New file: SphereInteractionManager.swift

      
The SphereInteractionManager responds to manipulation
      events in three stages: beginning a manipulation, updating the sphere's position, and
      releasing it. Original spheres remain fixed while movable clones follow the user's
      interaction.

      

    

    

      
Step 4

      
Wire the Manager into the View

      
Give ImmersiveView a
      SphereInteractionManager, mark the three spheres as
      originals with their fixed positions, make them interactive, and subscribe the manager
      to the scene's manipulation events.

      

    

    

      
Step 5

      
Create a Movable Clone

      
Original spheres never leave their fixed positions. When the user starts
      manipulating an original sphere, create a movable clone with the same color,
      glow, and interaction components. The clone joins the movable sphere collection —
      these clones are what overlap and mix colors.

      

    

    

      
Step 6

      
Create the Selection Ring

      
＋ New file: SphericalSelectionRim.swift

      
A thin white ring shows which sphere is selected. It is built from a custom ring
      mesh rather than a torus, so no extra geometry shows through the translucent sphere,
      and a BillboardComponent keeps it facing the viewer.

      

    

    

      
Step 7

      
Show the Ring on the Selected Sphere

      
Keep a single ring. When the selection changes, remove it from the previous sphere
      and attach it to the new one.

Section 4 of 6

    
Mix Colors

    
Store RGB values and combine them when two light sources overlap.
    Combining red and green produces yellow; red and blue produce magenta; when all three
    primary lights overlap, the result becomes white.

  

  

    

  






  

    

      
Step 1

      
Combine RGB Colors

      
The mixed(with:) function adds the RGB components of
      two colors together and normalizes the result to the
      0...1 range.

      
    
        
  • Red + Green → Yellow
    • 
        
  • Red + Blue → Magenta
    • 
        
  • Green + Blue → Cyan
    • 
      

      

    

    

      
Step 2

      
Detect Overlapping Spheres

      
＋ New file: SphereOverlapSystem.swift

      
The SphereOverlapSystem compares the world-space
      positions of every pair of movable spheres. If the distance between two centers is
      smaller than the overlap distance, the spheres overlap and the midpoint becomes the
      location of the color-mixing interaction.

      

    

    

      
Step 3

      
Describe the Overlap

      
Each overlap is described by a SphereOverlap value —
      the two spheres, the midpoint position, the mixed color, and a unique key that
      prevents duplicate interaction targets for the same pair.

Section 5 of 6

    
Add Overlap Targets

    
Create an invisible interaction point at the location where two RGB
    spheres overlap, so the user can interact with the mixed color without directly
    manipulating the original spheres.

  

  

    

  






  

    

      
Step 1

      
Store Overlap Information

      
＋ New file: OverlapVisualComponent.swift

      
OverlapVisualComponent keeps the overlap key and the
      mixed RGB color associated with the target. The key identifies which pair of spheres
      produced the target.

      

    

    

      
Step 2

      
Create the Overlap Target

      
Create an invisible ModelEntity at the midpoint of the
      overlapping spheres. It needs no visible mesh — a
      CollisionComponent,
      InputTargetComponent, and
      ManipulationComponent make it respond to the user's
      gesture.

      

    

    

      
Step 3

      
Create the Mixed Sphere

      
When the user starts manipulating an overlap target, build a sphere with the mixed
      color at the target's position and let it follow the drag. Once the gesture ends, the
      target has done its job and is removed; the mixed sphere joins the movable collection.

Section 6 of 6

    
Control Light with Your Right Hand

    
Use ARKit hand tracking to adjust the selected sphere's light
    intensity. With all five fingers extended, rotate your right wrist from palm-down to
    palm-up. The sphere changes its emissive intensity and glow opacity while keeping the
    same size.

  

  






  

    

      
Step 1

      
Store Light Intensity

      
SphereLightComponent stores brightness on each sphere.
      The range is 0.0...2.4, with
      1.2 as the initial value.

      

    

    

      
Step 2

      
Apply Brightness to the Sphere

      
Normalize the stored intensity, then update the material's base color,
      transparency, and emissiveIntensity. Update the glow's
      opacity separately, so brightness changes without changing the sphere's size.

      

    

    

      
Step 3

      
Convert Wrist Rotation to Brightness

      
＋ New file: RightHandLightDialController.swift

      
Process only the right-hand anchor. When all five fingers are extended, map the
      palm normal from down to up into a 0...1 brightness value,
      then smooth both the input and the applied intensity to prevent sudden jumps.

      

    

    

      
Step 4

      
Start Hand Tracking

      
＋ New file: HandTrackingManager.swift

      
An ARKitSession runs a
      HandTrackingProvider. After the user grants permission,
      each hand anchor update is forwarded to the dial controller.

      

    

    

      
Step 5

      
Expose Light Selection

      
The manager already tracks the selected sphere. Add small methods so the dial can
      read it, fall back to the nearest movable sphere, and apply an intensity.

      

    

    

      
Step 6

      
Connect Tracking to the Selected Sphere

      
Create the controller in ImmersiveView. A selected
      sphere takes priority; otherwise, use the closest light sphere to the wrist. The
      controller applies each smoothed intensity value through
      applySphereLightIntensity.

      

    

    

      
Step 7

      
Give Mixed Spheres an Initial Brightness

      
When two spheres create a mixed sphere, initialize its intensity with the average
      of the two source values. This is a snapshot: later changes to either source do not
      automatically change an already-created mixed sphere.
