# ``WaterLightTutorial``

visionOS에서 RealityKit과 ARKit 핸드 트래킹으로 물 표면의 빛 반사를 손으로 조정하는 예제를 만듭니다.

## Overview

이 패키지는 단계별 튜토리얼 문서를 제공합니다. <doc:MeetWaterLight>에서 시작하세요.

- 물 표면 엔티티와 커스텀 셰이더 머티리얼 구성
- `HandTrackingProvider`로 손 관절 추적
- 손 위치·핀치 제스처를 빛의 방향/세기 파라미터에 매핑
